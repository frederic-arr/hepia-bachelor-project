# Checklist pré-rendu

## "Fonctionnel"
- [ ] Tous les outils externes sont référencé
- [ ] Toutes les figures ne venant pas de nous sont sourcées
- [ ] Toute les extraits de code repris du repo sont sourcé
- [ ] La bibliographie est correcte (auteur, titre, lien)
- [ ] Tous les chapitres numérotés contiennent une amorce
- [ ] Toutes les données présentées sont valide
- [ ] Les acronymes sont écrits en toute lettre

- [ ] Toutes les légendes sont correctes
- [ ] Il n'y a plus de TODO

## Rédactionnel
- [ ] Voix passive
- [ ] Pas de pronoms personnels (on, je, nous)
- [ ] Pas de rotation des synonymes
- [ ] Pas de formulations prudentes ou atténuées
- [ ] Pas de formulations péjorative ou décrivant négativement le projet
- [ ] Pas de adjectifs promotionnels ou subjectifs
- [ ] Pas de phrases trop longues ou complexes
- [ ] Normes typographiques français suisse (pas d'espaces avant les ponctuions :?!)
- [ ] Pas de paragraphes trop court ne contenant qu'une ou deux phrases
- [ ] Pas de temps autre que le présent (pas de futur, de passé, ou de conditionnel, sauf si requis)
- [ ] Syntaxe et orthographe OK
- [ ] Lissage stylistique
  - [ ] Pas de produits en minuscule en début de paragraphe
  - [ ] Harmoniser utilisation de l'italique, des guillemets et des code inline
  - [ ] utiliser "etc." ou "..." de manière homogène
  - [ ] Utiliser le système en puissance de 2 (MiB, pas MB)

## Final

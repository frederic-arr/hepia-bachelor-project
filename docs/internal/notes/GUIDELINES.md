# Guidelines

## Commit Style

See [Conventional Commits 1.0.0](https://www.conventionalcommits.org/en/v1.0.0/).

The `type` follows [Angular's contributing guidelines](https://github.com/angular/angular/blob/22b96b9/CONTRIBUTING.md#type).

## Versioning

See [Semantic Versioning 2.0.0](https://semver.org/spec/v2.0.0.html).

Before initial release, tags corresponding to the different milestones will have the following format: `v0.0.0-dev.${epic_no}.${epic_name}`.
